# 2Touch

Static website for all-ages soccer recruiting, player development, and professional pathways.

Boys and girls. Youth through adult. Recreational to elite.

This repo still uses the old GitHub name `pitchpath`. The live brand name in the UI is 2Touch. The dedicated repo is:

https://github.com/kevinxramirezx21-maker/2Touch

## Live the site on GitHub Pages

1. Open the repo on GitHub.
2. Go to Settings, then Pages.
3. Under Build and deployment, set Source to Deploy from a branch.
4. Branch: main, folder: / (root).
5. Save.

## Pages

- index.html — home
- about.html — mission and method
- programs.html — age groups and development tracks
- recruiting.html — how scouting works
- pathways.html — college, pro, and coaching routes
- apply.html — player and parent interest form
- contact.html — club and scout contact
